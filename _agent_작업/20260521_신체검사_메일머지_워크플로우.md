# 스쿨커넥트 — 신체검사 → 가정통신문 메일머지 워크플로우

## 개요
학교에서 매년 하는 신체검사 결과를 바탕으로 개인별 가정통신문(신체발달상황 및 시력검사 결과 안내)을 대량 생성하는 파이프라인.

## 입력
1. **신체검사 결과표 PDF** — NEIS 출력물 또는 학교 자체 기록지. 손글씨 스캔 문서
2. **가정통신문 템플릿 HWPX** — 메일머지 필드({{키}}, {{이름}} 등)가 설정된 양식

## 출력
학생 개인별 HWPX 파일 24개 (또는 N개)

## 핵심 파이프라인

### 1단계: 데이터 추출 (OCR)
- PDF는 대부분 손글씨 스캔 문서
- **절대 EasyOCR/Tesseract 단독 사용 금지** — 한글 손글씨 숫자 인식률 매우 낮음
- **GPT-5.5 Vision에 위임** → `delegate_task`로 vision-capable subagent에 이미지 분석 요청
- 결과: 학생명단(이름/성별/키/몸무게/시력좌/시력우/안경착용)

### 2단계: 사용자 검증
- OCR은 24명 기준 보통 3~8건 정도 오인식
- 엑셀(CSV)로 추출 결과를 제공하고 사용자가 직접 수정하게 함
- 수정 패턴 예시: "단예준 137.7", "유예준 시력 0.1 1.2" (보통 1명당 1개 값만 틀림)

### 3단계: HWPX 메일머지 생성
- **절대 XML 문자열 replace 금지** — `str.replace()`, `re.sub()` 사용 시 파일 깨짐
- 반드시 `lxml.etree`로 파싱 → 수정 → 직렬화
- **핵심: 텍스트 수정한 모든 `<hp:p>`에서 `<linesegarray>` 반드시 삭제**
  (이게 줄배치 캐시인데 안 지우면 한글에서 글자 겹침)
- mimetype은 ZIP 첫 번째 항목, ZIP_STORED(비압축) 필수

### 4단계: 검증
- ZIP 무결성 확인 (`zf.testzip()`)
- XML 내 `{{...}}` 잔여 플레이스홀더 검사 (정규식)
- 값이 제대로 치환되었는지 샘플 확인
