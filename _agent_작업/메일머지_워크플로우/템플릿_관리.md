# 템플릿 관리 — 매년 반복되는 가정통신문

## 템플릿 보관소

모든 HWPX 템플릿은 **인박스/** (또는 학교공유드라이브)에 보관.
연도별로 하위 폴더 구성:

```
인박스/
├── 템플릿/
│   ├── 2026/
│   │   ├── 신체발달상황.hwpx
│   │   ├── 구강검진결과.hwpx
│   │   ├── 소변검사결과.hwpx
│   │   └── 건강검진결과.hwpx
│   └── (연도별...)
├── _agent_작업/          ← 출력물
└── (PDF 원본들)
```

## 템플릿 준비 방법

### 새 템플릿 만들기
1. 한글에서 기존 가정통신문 열기
2. 데이터가 들어갈 자리에 `{{필드명}}` 입력
3. 메일머지 필드 등록 (한글: 입력→메일머지→필드등록)
4. HWPX 저장

### 필드명 컨벤션 (통일 권장)

| 표준 필드명 | 설명 | 예시 |
|------------|------|------|
| 학년 | 학년 | 5 |
| 반 | 반 | 3 |
| 번 | 출석번호 | 1~24 |
| 이름 | 학생 이름 | 공서희 |
| 성별 | 성별 | 여 |
| 키 | cm | 144.8 |
| 몸무게 | kg | 40.1 |
| 표준체중 | (키-100)×0.9 | 40.3 |
| 체질량지수 | BMI | 19.1 |
| 왼쪽 | 왼쪽시력 | 0.8 |
| 오른쪽 | 오른쪽시력 | 1.0 |
| 안경착용 | 안경여부 | 예 |

## 연간 가정통신문 일정

학교에서 매년 비슷한 시기에 나가는 가정통신문:

| 시기 | 문서명 | 입력 데이터 | 난이도 |
|------|--------|------------|--------|
| **3월** | 개인정보 수집·이용 동의 | 이름 + 체크 | 하 |
| **3월** | 응급처치 동의 | 이름 + 체크 | 하 |
| **4월** | 신체검사 결과 안내 ★ | 키/몸무게/시력 | **상** |
| **5월** | 구강검진 결과 안내 | 충치/치아상태 | 중 |
| **5월** | 소변검사 결과 안내 | 이상여부 | 하 |
| **6월** | 1차 학부모 통지표 | 성적/행동발달 | 중 |
| **7월** | 여름방학 안내 | 이름만 | 하 |
| **9월** | 2차 학부모 통지표 | 성적/행동발달 | 중 |
| **10월** | 건강검진 결과 안내 | 비만도/혈압 | 중 |
| **12월** | 겨울방학 안내 | 이름만 | 하 |
| **12월** | 3차 학부모 통지표 | 성적/행동발달 | 중 |
| **2월** | 졸업/진급 안내 | 이름만 | 하 |

★ 신체검사는 OCR 필요한 유일한 문서 (손글씨 PDF).
나머지는 NEIS에서 CSV/엑셀로 추출 가능.

## 템플릿 재사용 전략

### 전략 A: 완전 자동 (권장)
1. 템플릿 필드명 통일 (`{{이름}}`, `{{키}}` 등)
2. 데이터만 CSV로 준비
3. `mailmerge.py` 실행
4. 내년에는 템플릿 복사 + CSV만 바꾸면 끝

### 전략 B: 반자동 (OCR 필요한 경우)
1. PDF 스캔본 → GPT-5.5 Vision OCR
2. 검증 후 CSV 확정
3. `mailmerge.py`로 생성

### 전략 C: 수합 플랫폼 연동 (미래)
1. 스쿨커넥트 웹앱에서 템플릿 등록
2. 선생님이 온라인에서 데이터 입력
3. 버튼 한 번으로 HWPX 일괄 생성
