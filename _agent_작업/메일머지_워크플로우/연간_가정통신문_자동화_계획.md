## 2. 자동화 전략

### 2-A. 데이터 출처별 분류

```
[NEIS CSV]                    [교사 직접]               [OCR 필요]
  ┌─────────┐               ┌──────────┐              ┌──────────┐
  │ 성적     │               │ 방학 안내 │              │ 신체검사  │
  │ 구강검진 │               │ 동의서   │              │          │
  │ 소변검사 │               │          │              │          │
  │ 건강검진 │               │          │              │          │
  └─────────┘               └──────────┘              └──────────┘
       ↓                         ↓                        ↓
  CSV 다운로드               내용 직접 입력             GPT-5.5 Vision
  후 포맷만 정리             (대부분 이름만)            OCR + 검증
       ↓                         ↓                        ↓
  ┌────────────────────────────────────────────────────────────┐
  │              mailmerge.py  (공통 엔진)                      │
  │         템플릿(HWPX) + 데이터(CSV) → 개인별 HWPX N개        │
  └────────────────────────────────────────────────────────────┘
```

### 2-B. 우선순위

| 우선순위 | 문서명 | 이유 |
|:--------:|--------|------|
| **1** | 신체검사 결과 | ✅ 이미 완료, OCR 필요 |
| **2** | 성적 통지표 (1/2/3차) | NEIS CSV 추출 가능, 수요 높음 |
| **3** | 구강검진/소변검사/건강검진 | NEIS CSV, 템플릿만 준비 |
| **4** | 방학 안내/동의서 | 이름만 넣으면 끝, 템플릿만 있으면 됨 |

## 3. 구현 방안: 3단계 로드맵

### Phase 1 ✅ (완료) — 신체검사 메일머지
- OCR → CSV → HWPX 생성 파이프라인 구축
- `mailmerge.py` 스크립트 완성
- 템플릿/필드 분석 완료

### Phase 2 — 템플릿 라이브러리 구축 (지금부터)

목표: **인박스/템플릿/** 디렉토리에 연도별 템플릿 정리

```
인박스/템플릿/2026/
├── 01_신체발달상황.hwpx          (MAILMERGE: 학년,반,번호,이름,성별,키,몸무게,표준체중,체질량지수,왼쪽,오른쪽,안경착용)
├── 02_구강검진결과.hwpx          (MAILMERGE: 이름,번호,치아우식,치석,치료필요)
├── 03_소변검사결과.hwpx          (MAILMERGE: 이름,번호,이상유무,비고)
├── 04_건강검진결과.hwpx          (MAILMERGE: 이름,번호,비만도,혈압,시력좌,시력우,청력)
├── 05_학부모통지표_1차.hwpx      (MAILMERGE: 이름,번호,국어,수학,사회,과학,영어,...행동발달)
├── 06_여름방학안내.hwpx          (MAILMERGE: 이름)
├── 07_학부모통지표_2차.hwpx
├── 08_겨울방학안내.hwpx          (MAILMERGE: 이름)
├── 09_학부모통지표_3차.hwpx
└── 10_개인정보동의.hwpx           (MAILMERGE: 이름)
```

**만드는 방법**: 기존에 학교에서 쓰는 hwpx 파일을 한글에서 열고, 데이터 들어갈 자리에 `{{필드명}}` 입력 후 저장.

### Phase 3 — 크론잡/자동 알림

**시즌 알림** (3~10월):
```bash
# 매년 4월 1일 → "신체검사 시즌입니다. PDF 넣으세요?"
# 매년 6월 1일 → "1차 성적 통지표 시즌입니다."
```

**자동 실행**:
```bash
# 인박스/에 PDF + HWPX 쌍이 들어오면 자동으로 메일머지 실행
# → cron job + script watcher
```

## 4. NEIS 데이터 추출 가이드 (나중에)

대부분의 가정통신문 데이터는 **NEIS에서 CSV/엑셀로 추출** 가능:
1. NEIS → 각종현황 → (원하는 항목) → 출력 → 엑셀 저장
2. 컬럼명을 템플릿 필드명과 일치하도록 정리
3. `mailmerge.py` 실행

---

## 5. 스쿨커넥트 웹앱 연동 (장기)

지금은 에이전트가 CLI로 처리하지만, 언젠가 웹앱에서:
1. 템플릿 업로드 (관리자)
2. CSV 업로드 or 온라인 입력 (담임)
3. "가정통신문 생성" 버튼 → HWPX 일괄 다운로드
4. 생성 이력 조회 (언제, 누가, 어떤 템플릿)

**웹앱이 필요한 순간**: 다른 선생님들도 써야 할 때.
**지금은 나만 쓰니까 CLI로 충분**.
