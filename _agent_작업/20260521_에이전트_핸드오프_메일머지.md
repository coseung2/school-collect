## 스쿨커넥트 메일머지 기능 — 에이전트 핸드오프

### 작업 내용
신체검사 결과표 PDF를 읽어서 HWPX 가정통신문 템플릿에 메일머지로 주입, 개인별 문서 N장 생성하는 파이프라인을 스쿨커넥트에 추가.

### 사용자 요구사항
1. 선생님이 신체검사 PDF + HWPX 템플릿을 인박스에 넣으면
2. 에이전트가 자동으로 데이터 추출 → 검증용 엑셀 제공 → 확인 후 메일머지 생성
3. 연도별/학급별로 재사용 가능하게

### 핵심 워크플로우

**Step 1 — PDF 데이터 추출**
- PDF는 손글씨 스캔 문서. EasyOCR 단독 금지.
- 반드시 GPT-5.5 Vision subagent(delegate_task)에 이미지 분석 위임
- 출력: 학생명단(이름/성별/키/몸무게/시력좌/시력우/안경착용)

**Step 2 — 사용자 검증**
- 추출 결과를 엑셀(UTF-8 BOM CSV)로 제공
- 사용자가 "단예준 137.7" 식으로 수정 보내면 즉시 반영
- 24명 기준 평균 3~8건 수정 발생

**Step 3 — HWPX 메일머지 생성**
- lxml.etree로 XML 수정 (str.replace 절대 금지)
- {{필드}} 텍스트 + FieldValue/Command 파라미터 모두 교체
- 수정한 모든 `<hp:p>`에서 `<linesegarray>` 반드시 삭제 (줄배치 캐시)
- mimetype → ZIP_STORED 첫 항목

**Step 4 — 검증 및 출력**
- ZIP 무결성, 잔여 플레이스홀더, 값 치환 확인
- 출력: `인박스/_agent_작업/가정통신문_출력물/`

### 필수 금지 규칙
- XML을 문자열로 replace/re.sub/f-string 조작 ❌ → lxml ✅
- linesegarray 미삭제 ❌ → 수정마다 삭제 ✅
- 폴더 없이 원본 덮어쓰기 ❌ → _agent_작업/에 사본 ✅
