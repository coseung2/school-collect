# Google Docs 분석 — 월중 교육 계획 수합

원문: https://docs.google.com/document/d/15HeWnTlPU7DRABfDxITW9wqtSxaFvIiFlj1fzy_jPMc/edit?usp=sharing

## 문서 성격

이 문서는 `2026학년도 6월 교육 계획` 형태의 월중 교육계획표다. 표 구조는 `주차 / 날짜 / 추진 내용` 3열이다. 월중계획은 단순 수합물이 아니라 학교 구성원 모두가 일정을 파악하기 위해 보는 최종 공개 문서다. 현재 Google Docs는 입력과 최종 열람이 같은 파일에서 함께 이루어지는 방식으로 보인다.

단, 문서 안에 `2026학년도 4월 교육 계획`과 `2026학년도 6월 교육 계획`이 함께 남아 있어 제목 정리가 필요하다. 실제 날짜는 6.1.~6.30.이므로 현재 분석 기준은 6월이다.

## 추출 결과

- 표 헤더: 주차, 날짜, 추진 내용
- 날짜 행: 22개
- 실제 추진 항목: 24개
- 비어 있는 날짜/입력 후보 행: 9개
- 입력 요령 주석: 1개

## 현재 Google Docs 방식의 문제

- 입력용 문서와 최종 공개 문서가 섞여 있어 작성 중인 내용도 모두에게 보인다.
- 여러 사람이 같은 월간표를 직접 수정해서 충돌/누락 확인이 어렵다.
- 담당자는 누가 제출했는지, 누가 미제출인지 보기 어렵다.
- 한 날짜에 여러 항목이 들어가면 형식이 제각각이 된다.
- 수업공개/협의회처럼 한 줄 안에 여러 세부 항목이 들어가면 나중에 정렬·필터링하기 어렵다.
- 최종본은 학교 구성원이 보기 쉬운 읽기전용 월간표로 배포되어야 한다.
- 매월 같은 표를 다시 만들고 안내해야 한다.

## school-collect 적용 방향

이 양식은 `교직원별 반복목록 입력 + 담당자 검토/확정 + 전체 구성원 공개 열람` 구조가 맞다. 핵심 산출물은 담당자만 보는 취합표가 아니라, 학교 구성원 모두가 보는 월중계획표다.

### 입력자 화면

- 교직원은 자기 일정/업무만 입력한다.
- 처음에는 빈 일정 1행만 보여준다.
- 필요한 만큼 `일정 추가`로 행을 늘린다.
- 입력 필드: 날짜, 구분, 추진 내용, 시간/기간, 장소, 대상/참석자, 담당자, 비고
- 최종 표시 문구는 자동 생성하되, 필요하면 직접 수정 가능하게 둔다.

### 담당자 편집/확정 화면

- 모든 제출자의 항목을 날짜순으로 누적한다.
- 제출자별/부서별/구분별 필터를 제공한다.
- 미제출자를 확인한다.
- 중복/표현/날짜 오류를 정리한 뒤 월중계획을 `확정`한다.
- CSV/엑셀 또는 Google Doc 양식에 가까운 표로 내보낸다.

### 전체 구성원 열람 화면

- 확정된 월중계획을 `주차 / 날짜 / 추진 내용` 월간표로 보여준다.
- 학교 구성원이 일정 파악용으로 보는 읽기전용 화면이다.
- 날짜순 기본 보기, 이번 주 보기, 구분별 필터를 제공한다.
- 작성/수정 권한 없이 열람만 가능하게 한다.
- 필요하면 인쇄/PDF/링크 공유가 가능해야 한다.

## 기존 도서구입 양식과 다른 점

도서구입은 `학년/반 담임` 중심이지만, 월중 교육 계획은 `교직원/부서/업무담당자` 중심이다. 따라서 현재 `collect_submissions`의 `grade/class_num` 중심 제출 구조만으로는 부족할 수 있다.

권장 보완:

- `submitter_key` 추가: 교직원 또는 부서를 고유하게 식별
- `department` 추가: 교무기획부, 연구부, 학년부 등
- `role_label` 추가: 담임, 전담, 부장, 비교과 등

제안 SQL은 `schema-extension-staff-submissions.sql`에 따로 저장했다.

## 등록 판단

현재 앱에는 아직 `table` field_type이 없어서 이 문서를 그대로 정식 등록하면 불편하다. 임시로 textarea 방식 등록은 가능하지만, 담당자 수동 정리가 많이 남는다.

정식 구현 순서:

1. `table` field_type 구현
2. 교직원/부서 단위 제출 식별자 추가
3. 월간 교육계획 담당자 검토/확정 화면 추가
4. 학교 구성원용 읽기전용 월중계획 공개 화면 추가
5. 날짜별 누적표 + CSV/엑셀/PDF 또는 링크 공유 내보내기 추가
6. 이 템플릿 등록
