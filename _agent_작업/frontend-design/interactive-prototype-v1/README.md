# School Collect 인터랙티브 HTML 프로토타입 v1

## 열람 방법

- `index.html` 파일을 브라우저로 직접 열면 됩니다.
- 외부 패키지, 빌드 과정, 네트워크 연결 없이 동작하도록 inline CSS/JS만 사용했습니다.
- 권장 확인 폭: 모바일(390px), 태블릿(768px), 데스크톱(1200px 이상).

## 작동하는 버튼/기능

### 공통

- 상단 역할 탭: `선생님 입력`, `담당자 취합/확정`, `전체 열람` 화면 전환
- 주요 버튼 클릭 시 toast 알림 또는 상태 배지 변경

### 선생님 입력

- `월중계획 일정 행 추가`: 새 일정 행 추가
- 각 일정 행 `삭제`: 해당 행 삭제
- 날짜 수정: 주차 배지가 자동 변경
- `도서 행 추가`: 도서구입 신청 행 추가
- 각 도서 행 `삭제`: 해당 행 삭제 및 합계 재계산
- 도서 수량/정가 수정: 행별 합계, 총권수, 총금액 즉시 갱신
- `임시저장`: 작성 상태를 임시저장으로 변경하고 알림 표시
- `제출`: 제출 완료 상태로 변경하고 알림 표시

### 담당자 취합/확정

- `미제출만 보기`: 제출 현황 목록을 미제출 항목만/전체로 토글
- 주차 선택 셀렉트: 검토 보드 주차 변경
- `이번 주`: 6월 4주차 검토 보드로 이동
- `충돌 확인`: 6월 22일/25일의 일정 집중·충돌 의심 항목 강조
- `확정`: 검토 중 배지를 확정 완료로 변경하고 전체 열람 상태에 반영

### 전체 열람

- `월 보기`: 6월 달력형 그리드와 주요 일정 표시
- `주 보기`: 이번 주 중심의 요일별 일정표 표시
- `일 보기`: 선택 날짜 상세 카드 표시
- `이번 주`: 6월 4주차 주 보기로 이동
- 날짜 선택: 해당 날짜 일 보기로 이동
- `인쇄`, `PDF`, `공유`: 실제 파일 생성 대신 상태 문구와 알림으로 반응

## 샘플 데이터

월중계획 샘플에는 다음 일정 일부를 반영했습니다.

- 6.1 생태전환교육 및 환경교육 주간(~6.5, 전교생, 정민주)
- 6.3 지방선거
- 6.11 6월 1회 장량 꿈끼 나눔 버스킹(8:20~8:50, 강당, 송윤아)
- 6.17 교직원 심폐소생술교육(13:50~16:50, 전교직원, 꿈빛마루, 양정인)
- 6.22 7월 교육 계획 수합(~6/26, 전교직원, 교무기획부)
- 6.22 수업공개 1학년/보건/체육
- 6.24 전교어린이회의
- 6.25 수업공개 6학년/5학년

도서구입 샘플에는 `브로큰 컨트리`, `자몽살구클럽`, `정의란 무엇인가`를 포함했습니다.

## 디자인 의도

- 선생님이 바로 이해할 수 있는 업무 언어와 상태 배지를 사용했습니다.
- 모바일에서는 카드와 세로 흐름이 우선되도록 반응형을 구성했습니다.
- 월중계획은 문서형 표의 익숙함을 유지하되, 열람 화면에서는 월/주/일 전환으로 실제 사용성을 확인할 수 있게 했습니다.
- 과한 중첩 박스 대신 큰 카드, 명확한 도구막대, 단순한 일정 칩으로 정보 구조를 정리했습니다.
- `word-break: keep-all`과 `overflow-wrap: break-word`를 적용해 한글 단어가 한 글자씩 쪼개지지 않도록 했습니다.
