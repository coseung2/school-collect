School Collect 프론트 디자인 작업 폴더

이번 작업 목적
- 학교 업무수합 플랫폼의 화면 시안을 먼저 정리합니다.
- 원본 프로젝트 파일은 아직 건드리지 않고, 디자인 요구사항과 시안 자료를 이 폴더에 따로 모읍니다.

현재 반영된 핵심 요구사항
1. 선생님 입력 화면
   - 도서구입: 도서 행 추가/삭제
   - 월중계획: 일정 행 추가/삭제
   - 모바일/태블릿에서도 입력 쉬운 화면

2. 담당자 취합/확정 화면
   - 제출 현황
   - 미제출 확인
   - 전체 누적표
   - 도서구입 총권수/총금액
   - 월중계획 날짜순/주차별 검토 후 확정

3. 전체 구성원 열람 화면
   - 월중계획 최종본 읽기전용
   - 월 / 주 / 일 보기 전환 가능
   - 이번 주 보기
   - 인쇄/PDF에 어울리는 구성

추가 메모
- 월중계획은 단순 표 하나가 아니라, 월간 달력형 / 주간 업무표형 / 일간 상세형으로 전환되는 구조가 적합합니다.
- 최종 구현 전 HTML 시안과 스크린샷으로 먼저 확인합니다.

프로토타입 생성 기록
- interactive-prototype-v1/index.html: 세 역할 탭과 실제 동작 버튼을 포함한 단일 HTML 인터랙티브 프로토타입을 생성했습니다.
- interactive-prototype-v1/README.md: 열람 방법, 작동 버튼, 디자인 의도를 정리했습니다.
