# School Collect 디자인 시안 B · 담당자 파워툴형

## 산출물

- `index.html`: 단일 self-contained HTML 프로토타입
- 외부 빌드, 패키지 설치, 원본 프로젝트 소스 수정 없이 인라인 CSS/JS만 사용했습니다.

## 시안 방향

B안은 담당자가 수합 마감 전후에 사용하는 **데이터 밀도 높은 파워툴형 대시보드**입니다.

핵심 구성은 다음과 같습니다.

1. **제출 현황**
   - 전체 제출률, 미제출 인원, 충돌 일정, 확정 대기 KPI 표시
   - 부서/학년별 제출 현황 표 제공

2. **미제출 관리**
   - 미제출자 리스트 표시
   - 개별 독촉, 전체 독촉, 명단 복사 버튼 제공
   - 상태 필터에서 미제출만 보기 가능

3. **월중계획 주차별 확정 검토**
   - 기본 진입 화면은 `주 보기 + 확정 큐`
   - 2026년 6월 3주차 기준으로 요일별 일정 검토
   - 충돌 일정은 붉은색, 검토 대기는 노란색으로 구분
   - 각 일정에 제출, 검토, 확정 상태 표시

4. **전체 누적표**
   - 일자, 시간, 업무명, 대상, 장소, 담당, 부서, 제출, 검토, 확정, 메모를 한 표에서 확인
   - 부서, 상태, 검색 필터와 연동

5. **월/주/일 보기 전환**
   - 주 보기: 담당자 기본 화면, 주차별 확정 검토 중심
   - 월 보기: 월간 누락·충돌 흐름 확인
   - 일 보기: 특정 날짜의 시간·장소 충돌 상세 검토

6. **확정 큐**
   - 우선 처리 항목과 대기 항목 분리
   - 개별 확정, 보류, 메모 버튼 제공
   - 전체 확정 버튼은 미제출/충돌 잔여 시 경고 토스트 표시

## 사용 방법

브라우저에서 아래 파일을 직접 열면 됩니다.

```text
_agent_작업/frontend-design/sketches/B-coordinator-power/index.html
```

별도 서버 실행이나 패키지 설치가 필요하지 않습니다.

## 디자인 메모

- 모든 UI 문구는 한국어로 작성했습니다.
- 단어 쪼개짐을 줄이기 위해 `word-break: keep-all`을 적용했습니다.
- 과도한 박스 중첩을 피하고, 카드/표/리스트 중심으로 정보 밀도를 높였습니다.
- 담당자 실무 흐름에 맞게 `주 보기`를 기본 활성 화면으로 설정했습니다.
