# School Collect 디자인 시안 A안 - 선생님 친화형

## 개요

이 폴더는 School Collect 학교 업무수합 플랫폼의 **A안: 선생님 친화형 화면**을 단일 HTML 시안으로 구현한 결과물입니다.

- 따뜻한 크림·오렌지 계열 색상
- 복잡한 박스 중첩을 줄인 단순한 구성
- 모바일과 태블릿에서 누르기 쉬운 큰 입력칸과 버튼
- 교사용 업무 입력 화면과 월중계획 보기 전환을 한 페이지에 배치

## 포함 기능

- 월중계획 상단 탭 전환: **월 보기 / 주 보기 / 일 보기**
- 기본 표시 화면: **주 보기**
- 교사용 입력 폼
  - 날짜
  - 추진 내용
  - 대상
  - 장소
  - 담당
  - 비고
- 업무 입력 행 추가 버튼
- 업무 입력 행 삭제 버튼
- 마지막 남은 행 삭제 시 행은 유지하고 값만 초기화
- 좁은 화면에서 입력 행이 세로 카드 형태로 전환되는 반응형 레이아웃

## 파일

- `index.html`: 인라인 CSS와 인라인 JavaScript를 포함한 self-contained HTML 시안
- `README.md`: 시안 설명 문서

## 실행 방법

브라우저에서 `index.html` 파일을 직접 열어 확인합니다. 별도 빌드, 패키지 설치, 외부 리소스가 필요하지 않습니다.

## 주의 사항

이 결과물은 프론트엔드 디자인 시안입니다. 실제 데이터 저장, 로그인, 서버 연동 기능은 포함하지 않았습니다.
