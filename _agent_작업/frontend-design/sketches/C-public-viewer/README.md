# School Collect 디자인 시안 C · 월중계획 게시판형/전체 열람형

## 개요

이 폴더는 School Collect 학교 업무수합 플랫폼의 디자인 시안 C안을 단일 HTML로 구현한 산출물입니다.

- 화면 성격: **월중계획 게시판형 / 전체 구성원 열람형**
- 중심 사용자: 확정된 월중계획을 확인하는 교직원
- 기본 화면: **이번 주 보기**
- 전환 화면: 월 보기 캘린더, 주 보기 요일별 게시판, 일 보기 상세 카드
- UI 문구: 한국어
- 구현 방식: 외부 패키지 없이 `index.html` 내부에 CSS/JS 포함

## 파일

- `index.html`  
  self-contained 정적 HTML 디자인 시안입니다. 브라우저에서 바로 열어 확인할 수 있습니다.

## 포함 요소

- 상단 월 선택
- 월 / 주 / 일 보기 탭
- 이번 주 버튼
- 인쇄 버튼
- PDF 버튼
- 부서 / 학년 / 업무분류 / 공개범위 요약 필터
- 월 보기: 한 달 전체 흐름을 보는 캘린더 그리드
- 주 보기: 이번 주 월~금 일정 게시판형 컬럼
- 일 보기: 선택 날짜 상세 카드형 목록

## 설계 의도

- 제출·취합 기능보다 **최종 월중계획 열람성**에 집중했습니다.
- 교직원이 가장 자주 확인할 이번 주 일정을 기본 화면으로 배치했습니다.
- 월 보기는 일정이 많은 날짜에 텍스트를 과도하게 넣지 않고 핵심 일정과 `+N개` 형태로 요약했습니다.
- 일 보기는 시간, 행사명, 대상, 장소, 담당, 비고가 바로 읽히는 카드 구조로 구성했습니다.
- `word-break: keep-all`을 적용해 한국어 단어가 어색하게 쪼개지지 않도록 했습니다.
- 카드/박스 중첩을 줄이고 큰 구역 중심으로 화면을 구성했습니다.
