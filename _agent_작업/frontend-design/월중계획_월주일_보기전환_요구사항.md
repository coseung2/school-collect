# School Collect 프론트 디자인 요구사항

## 1. 월중계획 보기 전환 요구사항

월중계획은 최종 열람 화면에서 다음 3가지 보기 모드를 제공하는 방향으로 설계한다.

### A. 월 보기
- 한 달 전체 흐름을 달력처럼 확인
- 날짜별 주요 일정 요약 표시
- 각 날짜 칸에는 너무 많은 텍스트를 넣지 않고 핵심 일정 2~3개만 표시
- 일정이 많은 날은 “+N개” 또는 “더보기” 방식 사용

### B. 주 보기
- 실제 학교 업무 확인에 가장 많이 쓰는 기본 화면 후보
- 월~금 또는 월~일 기준으로 한 주의 추진 내용을 표처럼 표시
- 담당자 검토 화면에서는 주차별 정리와 확정에 활용
- 전체 구성원 열람 화면에서는 “이번 주 일정”을 먼저 보여주기 좋음

### C. 일 보기
- 특정 날짜의 상세 일정 확인
- 시간, 행사명, 대상, 장소, 담당, 비고를 한 화면에 정리
- 모바일에서 가장 읽기 쉬운 카드형 구성이 적합

## 2. 화면별 반영 방식

### 선생님 입력 화면
- 입력자는 복잡한 월/주/일 전환까지 볼 필요는 없음
- 날짜 선택 후 일정 행을 추가하는 방식이 우선
- 단, 내가 입력한 일정이 어느 주차에 들어가는지는 작게 표시하면 좋음

### 담당자 취합/확정 화면
- 월 보기: 전체 누락/중복 확인
- 주 보기: 실제 검토와 확정의 중심 화면
- 일 보기: 특정 날짜 일정 충돌 확인

### 전체 구성원 열람 화면
- 상단에 보기 전환 탭 제공: 월 / 주 / 일
- 기본 진입은 “이번 주” 또는 “주 보기” 추천
- 월 보기에서는 전체 흐름, 주 보기에서는 실무 확인, 일 보기에서는 상세 확인

## 3. 디자인 원칙

- 선생님들이 바로 이해할 수 있는 말 사용
- 달력 앱처럼 과하게 복잡하게 만들지 않기
- “월중계획 문서” 느낌은 유지하되, 웹에서는 보기 전환이 자연스럽게 되도록 구성
- 모바일에서는 일 보기와 주 보기가 먼저 편해야 함
- 인쇄/PDF는 월 보기 또는 주 보기에서 자연스럽게 출력 가능해야 함

## 4. 시안 생성 시 포함할 요소

- 상단: 월 선택, 이번 주 버튼, 보기 전환 탭(월/주/일)
- 좌측 또는 상단 필터: 부서/학년/업무분류
- 본문:
  - 월 보기: 캘린더 그리드
  - 주 보기: 요일별 일정 컬럼 또는 표
  - 일 보기: 상세 카드 리스트
- 하단/우측: 인쇄, PDF, 공유 링크 버튼
