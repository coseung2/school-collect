# School Collect 디자인 시안 v2 — 둥근 카드박스형 제외

## 반영한 피드백
- 둥근 카드박스형 탈락
- 카드 나열 대신 문서형, 표형, 타임라인형, 상황판형으로 재구성
- 큰 둥근 사각형, 그림자, 카드 그리드 사용하지 않음

## 새 시안

### D안 — 문서 장부형
- 방향: 학교 월중계획 원본 문서를 웹으로 옮긴 느낌
- 형태: HWP/엑셀 장부, 결재란, 주간 계획표, 입력 행
- 장점: 선생님들이 이미 아는 문서 구조라 낯설지 않음
- 약점: 새 웹서비스 느낌은 약함
- 추천 용도: 교사용 입력 화면 + 인쇄/PDF 친화 화면

### E안 — 타임라인 레일형
- 방향: 월중계획 흐름과 충돌 확인 중심
- 형태: 좌측 주차/날짜 레일, 중앙 시간순 라인, 우측 담당자 확정 패널
- 장점: 일정 흐름, 충돌, 미제출, 확정 대기가 잘 보임
- 약점: 처음 보는 사람에게는 D안보다 조금 새로움
- 추천 용도: 담당자 검토/확정 화면

### F안 — 상황판 스프레드시트형
- 방향: 교무실 업무 상황판처럼 빠르게 훑고 확정하는 화면
- 형태: 상단 명령줄, 상태 바, 요일별 상황판, 전체 수합표, 우측 확정 목록
- 장점: 담당자가 한 화면에서 거의 모든 업무를 처리 가능
- 약점: 일반 교사용 입력 화면으로는 정보량이 많음
- 추천 용도: 담당자 운영 화면

## 내 추천
- 교사용 입력/출력 기본: D안
- 담당자 검토/확정 기본: E안 또는 F안
- 가장 실전적인 조합: D안의 문서 친숙함 + F안의 전체 수합표 + E안의 충돌 타임라인
