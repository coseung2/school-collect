# School Collect 디자인 시안 비교

## 생성한 시안

### A안 — 선생님 친화형
- 목적: 일반 교사가 업무를 빠르게 입력하고, 이번 주 월중계획을 편하게 확인하는 화면
- 강점: 가장 덜 부담스럽고 입력 화면이 큼직함
- 약점: 담당자 대량 검토에는 정보 밀도가 낮음
- 적합: 교사용 입력 화면의 기본 방향

### B안 — 담당자 파워툴형
- 목적: 제출 현황, 미제출, 충돌 일정, 확정 큐를 한 화면에서 처리하는 화면
- 강점: 담당자가 수합/확정 업무를 빠르게 처리하기 좋음
- 약점: 일반 교사에게는 정보량이 많아 복잡해 보일 수 있음
- 적합: 담당자 취합/확정 화면의 기본 방향

### C안 — 전체 열람형
- 목적: 확정된 월중계획을 교직원이 월/주/일로 읽기 쉽게 보는 화면
- 강점: 최종 공지판처럼 읽기 좋고 인쇄/PDF 버튼이 자연스러움
- 약점: 입력/수합 기능보다는 열람에 특화됨
- 적합: 전체 구성원 열람 화면의 기본 방향

## 내 추천 조합

- 교사용 입력 화면: A안 기반
- 담당자 취합/확정 화면: B안 기반
- 전체 구성원 열람 화면: C안 기반

즉, 하나의 디자인만 고르는 것보다 역할별로 나누는 것이 맞습니다.

## 월중계획 보기 전환 기준

- 기본 진입: 주 보기
- 월 보기: 전체 흐름 확인
- 주 보기: 실제 업무 확인과 확정 검토
- 일 보기: 특정 날짜 상세 확인
