# School Collect 디자인 시안 F · 상황판 스프레드시트형 / 담당자 운영 화면

## 산출물

- `index.html`: 단일 self-contained HTML 프로토타입
- 원본 프로젝트 소스 수정 없이 지정 출력 폴더에만 생성했습니다.
- 외부 패키지, 빌드, 서버 실행 없이 브라우저에서 직접 열 수 있습니다.

## 시안 방향

F안은 기존 둥근 카드박스형 탈락 피드백을 반영해, **교무실 업무 상황판 + 스프레드시트형 담당자 운영 화면**으로 구성했습니다.

핵심 목표는 다음과 같습니다.

1. **각지고 빠르게 스캔되는 화면**
   - 둥근 카드, 큰 패널, 그림자 장식을 제거했습니다.
   - 선, 표, 상태 막대, 명령줄 중심으로 구성했습니다.
   - `border-radius`는 0~3px 범위만 사용하고, `box-shadow`는 사용하지 않았습니다.

2. **상황판 + 스프레드시트 구조**
   - 상단: 명령줄, 기간/주차/부서/상태/검색 필터
   - 중단: 제출률, 미제출, 검토 필요, 충돌, 확정 큐, 최종 공지 상태 바
   - 본문: 전체 폭 요일별 상황판과 원장형 수합표
   - 우측: 고정 확정 목록/처리 큐
   - 하단: 동기화 시각과 현재 화면 상태 로그

3. **월/주/일 전환 포함**
   - 기본 진입은 `주 보기`입니다.
   - `월 보기`: 월간 전체 흐름과 누락/충돌 위치를 빠르게 확인합니다.
   - `주 보기`: 담당자가 실제로 검토·확정하는 기본 운영 화면입니다.
   - `일 보기`: 특정 날짜의 시간·장소 충돌과 점검 항목을 세부 확인합니다.

4. **전체 열람과 담당자 검토의 동시 인상**
   - 최종 공지판처럼 전체 일정을 열람할 수 있습니다.
   - 동시에 담당자는 표의 제출/검토/확정 상태와 우측 확정 목록을 보고 바로 처리할 수 있습니다.

## 사용 방법

브라우저에서 아래 파일을 직접 열면 됩니다.

```text
_agent_작업/frontend-design/sketches-v2-no-card/F-command-sheet/index.html
```

## 디자인 제약 반영

- 한국어 UI 문구 적용
- `word-break: keep-all` 적용
- 단일 HTML 파일, 인라인 CSS/JS만 사용
- 원본 프로젝트 소스 수정 없음
- 둥근 카드박스형 금지 방향 반영
- `box-shadow` 미사용
- `border-radius` 0~3px 범위 유지
