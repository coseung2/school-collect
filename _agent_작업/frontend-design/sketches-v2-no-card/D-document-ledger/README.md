# School Collect 디자인 시안 D안 - 문서 장부형

## 개요

이 폴더는 기존 둥근 카드박스형 디자인 탈락 피드백을 반영해 만든 **D안: 문서 장부형 / 학교 월중계획 원본 문서의 웹화** 시안입니다.

방향은 HWP·엑셀로 배포되던 학교 월중계획 문서를 웹 화면으로 옮긴 형태입니다. 카드형 그리드, 큰 둥근 박스, 그림자 효과를 배제하고 각진 표, 얇은 구분선, 결재란, 장부형 입력 행으로 구조를 잡았습니다.

## 디자인 원칙

- 둥근 카드박스형 금지 피드백 반영
- `border-radius: 0` 중심 사용, 큰 둥근 사각형 없음
- 그림자 효과 미사용
- 둥근 박스 배열 대신 문서 표와 장부 행 중심 구성
- HWP/엑셀 문서 같은 각진 표, 얇은 구분선, 공식 문서 느낌
- 색상은 문서 헤더, 검토 상태, 확정 상태 구분에만 제한적으로 사용
- 전체 UI에 `word-break: keep-all` 적용

## 포함 화면

- 상단 문서 제목 및 결재란
- 기준 월, 부서, 학년 필터
- 문서 인덱스형 보기 전환 탭
  - 월 보기
  - **주 보기 기본 표시**
  - 일 보기
- 주간 월중계획표
- 월간 축약 계획표
- 일일 세부 계획표
- 월중계획 입력 행 추가 영역
  - 입력 행 추가
  - 입력 행 삭제
  - 마지막 행 삭제 시 값만 초기화

## 파일

- `index.html`: 인라인 CSS와 인라인 JavaScript만 사용한 self-contained HTML 시안
- `README.md`: 시안 설명 문서

## 실행 방법

브라우저에서 `index.html` 파일을 직접 열어 확인합니다. 별도 빌드, 패키지 설치, 외부 리소스가 필요하지 않습니다.

## 주의 사항

이 결과물은 프론트엔드 디자인 시안입니다. 실제 데이터 저장, 로그인, 서버 연동 기능은 포함하지 않았습니다. 원본 프로젝트 소스는 수정하지 않았고 지정된 출력 폴더에만 파일을 생성했습니다.
