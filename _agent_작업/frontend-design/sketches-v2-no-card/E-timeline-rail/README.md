# School Collect 디자인 시안 E

## 방향

**타임라인 레일형 / 월중계획 흐름 확인** 시안입니다. 기존 둥근 카드박스형 탈락 피드백을 반영해 카드 나열 대신 문서형 선, 구분선, 행, 배지, 날짜 레일로 정보를 조직했습니다.

## 핵심 구조

- **좌측 날짜/주차 레일**: 월 전체에서 어느 주차와 날짜에 이슈가 있는지 빠르게 확인
- **중앙 시간순 라인**: 주 보기 기본 화면에서 일정 흐름, 시간 순서, 충돌 위치를 한 줄기 흐름으로 검토
- **우측 담당자 확정 패널**: 제출/미제출, 확정 대기, 충돌 조치 순서를 즉시 확인
- **월/주/일 전환**: 기본은 주 보기이며 월 보기는 전체 흐름 요약, 일 보기는 특정 날짜 상세 검토로 설계

## 반영한 상태 표시

- 제출 완료
- 미제출
- 충돌 일정
- 확정 대기
- 확정 완료

## 비카드 디자인 원칙

- `border-radius`는 0~2px 수준만 사용
- `box-shadow` 사용 없음
- 둥근 카드 묶음 대신 세로 레일, 표, 행 단위 구분선, 상태 배지 사용
- 한국어 UI 가독성을 위해 `word-break: keep-all` 적용
