# School Collect 업무 자동화 확장 (Chrome/Edge)

현재 탭의 주소와 제목을 School Collect 데스크톱 앱의 업무 버튼으로 등록합니다.
페이지 내용, 쿠키, 로그인 정보는 읽지 않고 보내지도 않습니다.

## 설치 (개발용, unpacked)

1. Chrome/Edge에서 `chrome://extensions`(Edge는 `edge://extensions`)를 엽니다.
2. 개발자 모드를 켭니다.
3. "압축해제된 확장 프로그램을 로드"로 이 저장소의 `apps/extension` 폴더를 선택합니다.

`manifest.json`의 `key`가 확장 ID를 고정하므로, 어느 컴퓨터에서 설치해도 ID가 같고
앱의 브리지 허용 목록과 일치합니다.

## 연결

1. School Collect 앱 → 왼쪽 메뉴 `업무 자동화` → `브라우저 확장 연결` 카드에서
   포트와 토큰을 확인합니다.
2. 확장 아이콘을 눌러 토큰을 붙여넣고 `토큰 저장` → `연결 확인`을 누릅니다.

토큰은 이 컴퓨터의 `chrome.storage.local`에만 저장됩니다.

## 사용

등록할 화면을 연 뒤 확장 아이콘을 누르고 `현재 화면 등록`을 누르면, 앱의
`내 업무 버튼` 목록에 바로 추가됩니다. 이름을 비우면 탭 제목을 사용합니다.

## 자동입력 레시피

같은 화면에서 반복 입력하는 칸을 미리 등록해 둘 수 있습니다.

1. 값을 넣을 화면을 엽니다.
2. 확장 팝업에서 `화면에서 요소 선택`을 누르고 페이지에서 입력 칸을 클릭합니다.
3. 위치 후보 중 하나를 고르고 필드 이름을 확인해 `필드 추가`를 누릅니다. 필요한 만큼 반복합니다.
4. 레시피 이름을 넣고 `자동입력 레시피 저장`을 누릅니다.
5. 같은 화면에서 `미리보기(dry-run)`를 누르면 각 필드를 찾았는지, 지금 값이 무엇인지 확인할 수 있습니다.
6. 넣을 값을 칸에 입력하고 `입력 실행`을 누르면 값을 채우고 결과를 다시 읽어 확인합니다.

필드가 없거나 여러 개 일치하거나 쓸 수 없는 칸이면 아무것도 입력하지 않고 중단합니다.
저장·제출 버튼은 누르지 않으므로 내용을 확인한 뒤 사이트에서 직접 저장하세요. 레시피는
화면 요소의 위치만 저장하고 입력한 값은 저장하지 않습니다.

## 표 입력 레시피 (학생 × 날짜)

출결·스포츠클럽처럼 학생 행과 날짜 열로 된 표는 표 단위로 등록합니다.

1. 표가 있는 화면에서 확장 팝업의 `표 등록(셀 클릭)`을 누르고 표 안의 칸을 클릭합니다.
2. 머리글에서 행 식별 열(학년·반·번호·이름 등)과 날짜 열을 찾아 보여 줍니다.
3. 레시피 이름을 넣고 `표 레시피 저장`을 누릅니다.
4. `표 미리보기`를 누르면 행 식별 값과 날짜 열의 현재 값이 탭으로 구분된 행렬로 채워집니다.
5. 값을 채워 `표 입력 실행`을 누르면 각 칸을 다시 읽어 확인하고 결과를 칸마다 보여 줍니다.

행 식별 값이 중복되거나, 저장한 머리글을 지금 표에서 찾지 못하거나, 입력 칸이 없거나
여러 개면 아무것도 입력하지 않고 중단합니다. 미리보기 이후 행이 바뀐 경우에도 중단합니다.
칸 일부만 검증에 실패하면 성공·실패를 구분해 표시하고, 저장·제출은 사용자가 직접 합니다.

## 감시 레시피 (새 신청·결재 확인)

체험학습 신청처럼 새 항목이 생기는 목록은 식별자만 비교해 알림을 만듭니다.

1. 목록이 있는 화면에서 확장 팝업의 `감시 등록(행 클릭)`을 누르고 행 안의 식별자
   (예: 신청번호)를 클릭합니다. 목록 행 위치와 행 안 식별자 위치를 함께 저장합니다.
2. 레시피 이름을 넣고 `감시 레시피 저장`을 누릅니다.
3. 같은 화면에서 `감시 실행`을 누르면 식별자 목록을 읽어 앱에 전달합니다.
4. 앱의 `업무 자동화` 화면에서 레시피별 항목 수·마지막 확인 시각·새 항목 수를 확인하고,
   `새 항목 확인`으로 알림을 지우거나 `감시 중지`로 잠시 멈출 수 있습니다.

저장되는 값은 새 항목 판별에 필요한 식별자와 확인 시각뿐입니다. 학생 이름·신청 사유 같은
본문은 저장하지 않습니다. 행이 없거나, 식별자가 중복되거나, 로그인 화면으로 바뀐 경우에는
알리지 않고 중단하며 이유를 표시합니다.

## 보안 경계

- 브리지는 `127.0.0.1:43110`에만 열리고, 토큰이 없으면 요청을 거부합니다.
- 브라우저가 보내는 `Origin` 헤더가 있으면 고정된 확장 ID와 같아야 합니다.
  따라서 웹 페이지는 토큰을 알아도 브리지를 호출할 수 없습니다.
- 브리지는 바로가기와 자동입력 레시피만 만들 수 있고, 임의 URL 열기나 임의 코드 실행은 하지 않습니다.
- 등록되는 값은 사용자가 보고 있는 탭의 제목과 주소뿐입니다. 주소에 계정 정보가
  들어 있으면 앱이 저장을 거부합니다.
- 페이지 조작은 고정 명령(`pick`, `preview`, `pick-table`, `preview-table`, `fill-table`,
  `pick-watch`, `watch-scan`)만 실행하며, 위치 종류는 `id`/`name`/`label`/`css`로 제한합니다.
  표 레시피는 표 위치와 머리글 텍스트만, 감시 레시피는 목록·식별자 위치만 저장하고 값은
  실행할 때만 페이지로 보냅니다.
